# Parallel DS · 另一边

一台 NDS 风格的网页双屏掌机，遇见平行世界中不同职业的自己。

纯 HTML、CSS 和 JavaScript，无需安装依赖。包含三个世界、预设对话、礼物口袋、开关机与可选按键音效。当前为本地交互原型，刷新会重置进度。

## 运行

直接用浏览器打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765/ 。

## 操作

- 点击下屏或机身按键操作。
- 方向键切换世界，Enter / A 确认，B / Escape 返回通讯。
- X 打开世界列表，Y 打开口袋。

这是独立的视觉与交互原型，与任天堂无关联，不包含游戏 ROM。
